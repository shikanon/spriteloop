# SpriteLoop

**输入一张图，让游戏角色循环动起来。**

SpriteLoop 面向独立游戏开发者和美术创作者，将单张角色或道具图片转换为游戏动作序列帧，提供循环预览，并导出可用于游戏引擎的素材。

> 当前状态：项目初始化与需求定义阶段。仓库已建立产品范围和技术边界，尚未实现或接入动画生成模型；下述能力均为开发目标。

## 核心流程

1. **上传图片**：导入 PNG、WebP 或 JPEG，预览原图；优先保留透明通道。
2. **描述动作**：选择待机、行走、奔跑等预设，或输入动作描述。
3. **生成动画**：设置帧数、播放帧率和输出尺寸，生成保持主体外观一致的动作帧。
4. **检查循环**：连续播放、逐帧检查，确认最后一帧到第一帧的动作衔接。
5. **导出素材**：下载透明 PNG 序列、Sprite Sheet + JSON 元数据，以及动画预览。

## MVP 范围

- 单张图片、单个主体、单个动作；首先完成待机循环。
- 统一画布尺寸与角色锚点，减少画面抖动、裁切和位置漂移。
- 提供帧数、FPS、尺寸控制，以及透明棋盘背景预览。
- 保存原始输入、生成参数和导出结果，支持复用素材与失败重试。
- 生成任务显示排队、处理、成功、失败状态与具体错误。
- 输出 PNG 序列、Sprite Sheet 和包含帧位置、时长、锚点的 JSON。

行走、奔跑和自定义动作将在待机流程验证后扩展；攻击、跳跃等一次性动作需单独设计播放模式。

## 开发路线

- [ ] 验证单图生成动作的模型方案：外观一致性、循环质量、耗时和成本。
- [ ] 完成素材上传、持久化与任务管理。
- [ ] 打通单图 → 待机动画 → 连续循环预览。
- [ ] 完成透明背景处理、帧对齐、序列帧与图集导出。
- [ ] 用真实图片完成端到端验收，再扩展动作预设。
